\# PostureGuard — Custom ML Training Pipeline

============================================



Train your own posture detection model using YOUR body,

YOUR camera angle, and YOUR posture patterns.



\## Project Structure



```

posture\_ml/

├── step1\_collect\_data.py      # Record posture frames from webcam

├── step2\_extract\_features.py  # Run MediaPipe, extract landmark features

├── step3\_train\_model.py       # Train \& evaluate classifier

├── step4\_realtime\_inference.py # Live webcam detection with your model

├── requirements.txt

└── data/

&#x20;   ├── raw\_frames/

&#x20;   │   ├── good/

&#x20;   │   ├── head\_forward/

&#x20;   │   ├── slouch/

&#x20;   │   ├── shoulder\_tilt/

&#x20;   │   └── neck\_bend/

&#x20;   └── features.csv           # Generated by step 2

└── models/

&#x20;   ├── posture\_model.pkl      # Trained model

&#x20;   └── confusion\_matrix.png   # Evaluation plot

```



\## Quick Start



\### 1. Install dependencies

```bash

pip install -r requirements.txt

```



\### 2. Collect data (5–10 minutes)

```bash

python step1\_collect\_data.py

```

\- Sit in each posture and hold the corresponding key

\- Aim for 300–500 frames per posture class

\- Keys: G=good, F=head\_forward, S=slouch, T=shoulder\_tilt, N=neck\_bend



\### 3. Extract features

```bash

python step2\_extract\_features.py

```

\- Runs MediaPipe on all frames

\- Saves 107 features per frame to data/features.csv



\### 4. Train the model

```bash

python step3\_train\_model.py

```

\- Trains Random Forest, Gradient Boosting, and SVM

\- Picks the best one automatically

\- Saves to models/posture\_model.pkl

\- Shows confusion matrix



\### 5. Run live detection

```bash

python step4\_realtime\_inference.py

```

\- Uses your trained model on live webcam feed

\- Shows prediction + confidence + per-class probabilities

\- Sends terminal alerts for bad posture



\## Tips for Better Accuracy



\- \*\*Lighting\*\*: Use consistent lighting when collecting and using

\- \*\*Camera angle\*\*: Keep the same webcam position always

\- \*\*Data balance\*\*: Try to have similar counts for each class

\- \*\*Variety\*\*: Move slightly while recording — don't stay frozen

\- \*\*More data\*\*: 500+ frames per class gives significantly better results



\## Feature Engineering Details



Each frame becomes a vector of 107 numbers:

\- 99 landmark coords: 33 landmarks × (x, y, visibility)

\- 8 computed angles/ratios:

&#x20; - neck\_angle\_L / neck\_angle\_R (joint angle at shoulder)

&#x20; - head\_forward (nose height vs shoulder midpoint)

&#x20; - shoulder\_tilt (left vs right shoulder height difference)

&#x20; - ear\_tilt (left vs right ear height difference)

&#x20; - spine\_lateral (shoulder midX vs hip midX)

&#x20; - torso\_height (shoulder-to-hip vertical distance)

&#x20; - nose\_offset\_x (nose vs shoulder center horizontal)



\## Extending the Model



Add new posture classes by:

1\. Adding the class to CLASSES dict in step1 and step2

2\. Collecting frames for that class

3\. Re-running steps 2, 3, 4



\## Model Performance (expected)



With 300+ frames per class:

\- Random Forest:       \~92–96% accuracy

\- Gradient Boosting:   \~91–95% accuracy  

\- SVM (RBF):           \~90–94% accuracy
